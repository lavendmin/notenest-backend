# presigned URL 의 X-Amz-Credential·X-Amz-Signature 는 가렸다. UUID 는 <uuid> 로 치환.
# 1번 db row 의 원본 파일명 깨짐은 Windows curl 이 한글 파일명을 CP949 로 보낸 탓 — UTF-8 로 보낸 재검증은 문서 참고.

## 2. 목록(비로그인) 커버 URL
list has image field: False, has full-demo text: 0
coverUrl: https://notenest-media.s3.ap-northeast-2.amazonaws.com/music/<uuid>/cover/<uuid>?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Date=20260925T134537Z&X-Amz-SignedHeaders=host&X-Amz-Credential=<masked>&X-Amz-Expires=3600&X-Amz-Signature=<masked>
GET coverUrl status=HTTP/1.1 200 OK content-type=image/png bytesEqual=true
